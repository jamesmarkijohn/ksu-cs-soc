# KSU SOC for CS
This is the repository for the Department of Computer Science's Security Operations Center (SOC) at Kent State University.

The goal of this project is to create an SOC that can be deployed to the Department of Computer Science's CyberRangeCZ Platform (CRCZP). This can then be used as a sandbox environment for students to complete tasks and assignments for security courses, providing a hands-on environment where practical skills can be applied.

Both a traditional SOC and an SOC enhanced with AI analysis tools will be provided. Current development efforts are focused on building the traditional SOC first, before using it as a template to integrate the AI analysis tools.

# This project is in active development
At present, this project is being actively developed and is not ready to be deployed for any practical usage. This section will be removed once the SOC has been built and adequately tested. Please reach out to the repository's maintainer, James Markijohn, with any questions.
